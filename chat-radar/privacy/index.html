처리하는 정보

대화 레이더는 회원가입이나 로그인 없이 쓰는 앱이에요. 앱을 쓰는 동안 앱 운영자는 이용자의 개인정보를 받지 않고, 정보를 받을 서버도 두지 않아요. 메일로 문의할 때만 답장에 필요한 정보를 받고, 받는 정보와 보관 기간은 아래 '문의'에 적었어요.

이용자가 카카오톡에서 직접 내보낸 뒤 고른 대화 파일(.txt, .zip, .csv, .eml)은 기기 메모리 안에서만 읽고 분석해요.

파일과 그 안에 든 이름·대화 내용은 서버로 보내지 않고, 어디에도 저장하지 않으며, AI 학습에 쓰지 않아요.

분석이 끝나면 원문은 메모리에서 버리고, 화면에는 날짜와 숫자로 정리한 결과만 남겨요. 앱을 닫거나 다시 열면 분석 결과도 사라져요.

'붙여 넣기'로 넣은 대화 글과 '대화상대 목록 붙여 넣기'로 넣은 목록 글도 같은 방식으로 기기 메모리에서만 쓰고 저장하지 않아요.

여러 방의 대화 파일을 함께 고르면 방마다 같은 방식으로 읽어요. 다른 방으로 바꿔 볼 수 있게 방마다 정리한 결과(이름과 날짜·숫자)를 기기 메모리에 함께 두고, 다른 파일을 고르거나 앱을 닫으면 사라져요.

분석에는 생성형 AI를 쓰지 않아요. 모든 결과는 앱 안 계산 기준 안내에 공개한 규칙으로 계산해요.

기기에 저장하는 정보

같은 방을 다시 분석할 때 지난 분석과 달라진 점(새로 떠난 사람과 새로 들어온 사람, 조용해진 사람 수, 안내 없이 줄어든 인원)을 알려 드리려고, 토스 앱이 미니앱에 주는 기기 저장 공간에 방마다 아래 값만 저장해요.

  • 방 식별값: 방 제목과 기록 시작 시각을 기기마다 만든 임의값과 섞어 만든 해시예요. 이 값으로 원래 방 제목을 알아낼 수 없어요.
  • 그 방에서 마지막으로 확인한 출입 기록(들어옴·나감·내보내짐)의 시각
  • 분석한 일시, 떠난 사람 수와 조용해진 사람 수 같은 집계 숫자
  • 대화 파일 제목에 적힌 그때의 인원 수와 그 기준 시각(제목에 인원이 있는 파일일 때만)
  • 방 식별값을 만들 때 쓰는 기기별 임의값

이름(원래 글자든 해시처럼 변환한 값이든)과 대화 원문은 저장하지 않아요. 직접 입력한 인원, '같은 사람으로 보기' 묶음, 대화상대 목록 대조 표시, 이름 가리는 방식(익명 별명)과 '바로 볼 결과' 선택도 저장하지 않아요. 저장한 값은 기기 밖으로 보내지 않아요.

최근 분석한 방 30개까지만 보관하고, 그보다 많아지면 오래된 것부터 지워요.

지우는 방법: 앱의 설정 화면에서 '저장된 기록 모두 지우기'를 누르면 바로 지워져요. 토스 앱을 삭제해도 함께 지워져요.

토스 SDK가 처리하는 정보

앱이 잘 동작하는지 확인하려고 토스 SDK의 이벤트 기록 기능으로 익명 사용 기록을 남겨요. 남기는 값은 아래와 같아요.

  • 열어 본 화면과 사용한 기능
  • 고른 파일의 종류(txt·zip), 파일 크기나 메시지 수의 대략적인 구간, 대화 형식 종류
  • 분석 성공 여부와 실패 이유 코드
  • 기기 운영체제 종류(Android·iOS)와 방 유형(단톡·1:1)
  • 토스 SDK가 기록마다 자동으로 붙이는 익명 사용자 키(anonymous_key, 앱 운영자는 이 키로 이용자의 이름이나 연락처를 알 수 없어요)

이름, 대화 내용, 방 제목, 파일 이름은 이 기록에 넣지 않아요. 이 기록은 앱인토스 플랫폼에서 처리되고, 토스의 앱인토스 운영 정책과 개인정보처리방침을 따라요.

앱을 무료로 제공하려고 광고를 보여 드려요. 광고는 토스 앱의 광고 SDK가 띄우고, 광고 노출·클릭 측정과 맞춤형 광고를 위해 광고 식별자 같은 기기 정보를 처리할 수 있어요. 이 처리는 앱인토스와 광고 네트워크의 정책을 따르고, 앱 운영자는 그 정보를 받지 않아요.

맞춤형 광고는 기기 설정의 광고 메뉴에서 끄거나 광고 식별자를 재설정할 수 있어요.

결과 카드를 저장하거나 공유하면 기기의 저장·공유 화면으로 넘어가요. 공유한 이미지는 이용자가 고른 앱의 정책을 따라요. 앱 링크 보내기는 토스 공유 기능을 쓰고, 링크에는 분석 결과나 이름이 들어가지 않아요.

대화 상대의 정보

대화 파일에는 내 대화뿐 아니라 대화 상대의 이름과 대화 내용도 들어 있어요. 내가 참여해 직접 받은 대화만 분석해 주세요.

다른 사람의 휴대폰에서 꺼낸 대화나 허락받지 않은 대화 파일은 분석하지 말아 주세요.

결과 화면과 공유 카드에서 이름은 기본으로 가려져 있어요. 이름을 보이게 바꿔 공유할 때는 같은 방 사람끼리만 공유해 주세요.

'익명 별명'을 고르면 이름을 '수줍은 수달'처럼 누구인지 알 수 없는 별명으로 바꿔 보여 줘요. 별명은 기기 안에서 무작위로 만들고 저장하지 않아요.

결과에는 대화 원문 문장을 넣지 않아요.
